# В моем эксперименте Release оказался быстрее Debug примерно в 7 раз

* в Debug присутствуют инструкции nop, которых нет в Release;
Когда я открыл метод в режиме Debug, там было много непонятных строк с командой nop. В Release этих строк вообще нет. Я так понял, nop — это просто «пустая операция». Она нужна, чтобы отладчик мог останавливаться на каждой строчке. В Release она не нужна, поэтому её убрали.

* в Release уменьшилось количество промежуточных операций с локальными переменными;
В Debug программа сохраняет каждую переменную в отдельную ячейку памяти, чтобы в отладчике можно было посмотреть её значение. В Release компилятор умный: он понял, что промежуточные переменные не нужны, и сократил количество операций. Кода стало меньше.

* количество IL-инструкций в методе Add() изменилось с 11 до 4.
